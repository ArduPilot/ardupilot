# RP2350 per-file optimisation registry
# format: path|level
#
# RP2350 builds at -Os because XIP flash bandwidth, not core speed, is the
# bottleneck. A few translation units sit on the main loop's critical path and
# are worth the extra flash at -O2. Listing them here rather than writing
# "#pragma GCC optimize" into the source keeps the chip name out of shared
# libraries, and puts the decision alongside the RAMFUNC2 and Scratch X/Y
# placement registries it is usually traded against.
#
# The level is appended to the compile line, so it wins over the board default.
# A path that is never compiled warns at the end of the build: a silent miss is
# a trap, because the build succeeds and the entry looks like it took effect.
