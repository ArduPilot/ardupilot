# RP2350 Scratch Y registry — SRAM9 (0x20081000, 4 KB), core1 dedicated I-CODE bus.
# Functions here get single-cycle instruction fetch on core1 with zero bus-fabric contention.
# Rule: core1-EXCLUSIVE hot paths only. If core0 also executes a function parked here it
# reaches SRAM9 over the bus fabric and contends with core1's dedicated I-CODE fetch.
# Budget: 3840 B (first 256 B of SRAM9 reserved for c1_vtable, see common_rp2350_smp.ld).
#
# IMPORTANT: functions listed here must NOT also appear in rp2350_ramfunc2_registry.txt.
# The linker claims .text sections first-come-first-served; duplicates would be silently dropped.
#
