# CRSF RC input drain (core0 only). PIOUART is IRQ-driven with no DMA, so every RX interrupt runs
# this to empty the PIO FIFO. At 420 kbaud that is a byte every 24 us into a shallow FIFO, and it
# was the port that went into continuous failsafe once core1's bdshot fetches started evicting
# core0 from the shared XIP cache. Fetching the drain itself from flash is the worst place for it.
libraries/AP_HAL_ChibiOS/PIOUART.cpp|ChibiOS::PIORXDriver::_service_rx_fifo  # 360 B
# Everything else the same interrupt runs, for the same reason. The drain was
# put here on its own, but the vector reaches it through Vector7C and the
# per-instance dispatcher, and the error poll and transmit drain were added
# either side of it later - so four fifths of the handler was still being
# fetched from flash 2100 times a second on the core this bank exists to
# protect. Measured at 3.95 us an interrupt with them in flash.
libraries/AP_HAL_ChibiOS/PIOUART.cpp|Vector7C  # 20 B, PIO0 IRQ0
libraries/AP_HAL_ChibiOS/PIOUART.cpp|Vector80  # 20 B, PIO0 IRQ1
